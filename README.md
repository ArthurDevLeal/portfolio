# 🎨 Portfólio Pessoal

Um portfólio pessoal moderno e de alta performance construído com **Next.js 16**, **React 19** e **shadcn/ui**. O projeto foca em um design limpo, animações fluidas e uma experiência totalmente responsiva.

## ✨ Seções

* **Apresentação (Hero)** – Introdução com links diretos para LinkedIn, GitHub e E-mail.
* **Projetos** – Vitrine dos meus melhores trabalhos com imagens, tecnologias utilizadas e links para demonstração e código.
* **Habilidades Técnicas** – Detalhamento da minha stack de front-end, back-end, bancos de dados e ferramentas de design.
* **Jornada** – Linha do tempo interativa narrando minha trajetória na programação desde 2022.
* **Sobre Mim** – Informações pessoais, objetivos profissionais e carta de apresentação.
* **Contato** – Formulário funcional com validação robusta utilizando React Hook Form e Zod.

## 🛠️ Tecnologias Utilizadas

* **Framework**: Next.js 16 (App Router)
* **Componentes de UI**: shadcn/ui
* **Estilização**: Tailwind CSS
* **Animações**: Motion e Lenis (Smooth Scroll)
* **Formulários**: React Hook Form com validação Zod
* **Temas**: Suporte a modo escuro (dark mode) com next-themes
* **Ícones**: Remix Icon e Lucide React
* **Linguagem**: TypeScript

## 🚀 Como Executar o Projeto

### Pré-requisitos

* Node.js 18 ou superior
* npm ou yarn

### Instalação

1.  Clone o repositório em sua máquina:
    ```bash
    git clone [https://github.com/ArthurDevLeal/seu-repositorio.git](https://github.com/ArthurDevLeal/seu-repositorio.git)
    ```

2.  Acesse a pasta do projeto e instale as dependências:
    ```bash
    npm install
    ```

3.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```

4.  Acesse [http://localhost:3000](http://localhost:3000) no seu navegador para visualizar o portfólio.

## 📁 Estrutura de Pastas

```text
├── app/                  # Rotas e layout principal (App Router)
├── components/           # Componentes modulares da interface
│   ├── hero-section/     # Seção de introdução
│   ├── projects-section/ # Vitrine de projetos
│   ├── tech-skills-section/ # Listagem de habilidades
│   ├── time-line-section/   # Linha do tempo da jornada
│   ├── about-section/    # Informações pessoais
│   └── ui/               # Componentes base reaproveitáveis (shadcn/ui)
├── data/                 # Arquivos JSON e TS com o conteúdo das seções
├── hooks/                # Hooks personalizados do React
├── lib/                  # Funções utilitárias e configurações
├── public/               # Ativos estáticos (imagens, ícones e fontes)
├── schemas/              # Esquemas de validação do Zod
└── types/                # Definições de tipos TypeScript
```
